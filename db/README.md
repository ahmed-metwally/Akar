# قاعدة البيانات

Postgres على Supabase، قاعدة واحدة مشتركة بين الخدمات (ADR-0001).

## الهجرات

- `migrations/0001_init.sql` — السكيمة الأولى: المستخدمون، التحقق، الوحدات، الإعلانات، الصور، المحادثة، الدفع، البلاغات، وسجل الأحداث مع منع التعديل والحذف عليه.
- `migrations/0002_rls.sql` — سياسات أمان مستوى الصف.

## قواعد لا تُكسر

1. **لا حذف صفوف.** الإلغاء والانتهاء حالات. الاستثناء الوحيد ملفات المستندات في التخزين، لا صفوف القاعدة (ADR-0004).
2. **لا أرقام قومية ولا صور مستندات في القاعدة.** يُخزَّن من التحقق نتيجته ومستواه وتاريخه والمراجِع وبصمة المستند.
3. **إعلان منشور واحد لكل وحدة لكل غرض** — مفروض بفهرس فريد جزئي.
4. **السعر إلزامي** في كل إعلان.
5. **كل تغيير ذي دلالة يولّد حدثاً** في `event`.

## التشغيل

```bash
psql "$DATABASE_URL" -f migrations/0001_init.sql
psql "$DATABASE_URL" -f migrations/0002_rls.sql
```

`app.user_id` يُضبط في كل طلب بهوية المستخدم قبل أي استعلام، وإلا لن تُرجع السياسات شيئاً.
